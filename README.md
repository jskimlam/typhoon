# 동북아 태풍 아카이브

Ventusky 실시간 바람지도와 기상청 공식 태풍정보·과거 통계를 함께 확인하는 GitHub Pages 대시보드입니다.

제작: **LAM JSKIM**

## 데이터 기준

- 태풍 발생·한국 영향 통계: 기상청 날씨누리 태풍발생현황
- 현재 위치·예상 경로·강도: 기상청 태풍 상세정보
- 실시간 바람·날짜/시간 지도: Ventusky 공식 임베드
- 장기 태풍 경로: 기상청 과거태풍 자료를 우선 사용하고 필요한 범위만 별도 정적 데이터로 관리 예정

> 이 프로젝트는 정보 탐색용입니다. 재난 대응 판단에는 기상청의 최신 통보문과 특보를 확인하세요.

## Android 앱

`android-app`은 공개 대시보드를 불러오는 경량 Android WebView 앱입니다. GitHub의 `v*` 태그가 푸시되면 설치 가능한 디버그 서명 APK가 Releases에 게시됩니다.
